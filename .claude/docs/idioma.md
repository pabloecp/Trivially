# Idioma (español / English)

- The site's texts are written in Spanish in the code. `tr("Texto en español")` (`translate`, `frontend/src/lib/i18n.js`) gives the same text, or its English when the language is English and `frontend/src/lib/en.js` has it. A text with no entry stays in Spanish, so nothing breaks when one is missing. `en.js` is the dictionary, keyed by the Spanish text.
- Every Spanish text in the frontend goes through `tr()` (or `t()` from `useT()`, the same function; the hook re-renders the component when the language changes). `App` re-draws the whole site on a change, so `tr()` is enough in any component: no hook is needed. It is read when the text is drawn, never when a file loads: a list of texts at the top of a file (a game's name and tagline, badges, skins, sound names) uses getters (`get name() { return tr("Trivia"); }`), so it follows the language.
- Numbers and dates use `locale()` (`en-US` or `es-ES`), never a fixed `"es-ES"`. A text that is compared (`title === tr("¡Empate!")`) is compared with the translated one.
- Gaps: `tr("Tu grupo · {n}", { n })`. Never join pieces of a sentence; give the whole sentence an entry. Counts and lines like "5 rondas · 10 s · Cerradas" are put together part by part (`UNITS` in `i18n.js`, an entry for each part).
- The server writes its messages in Spanish (errors, the day's challenge). They are translated on arrival: `emitAck`/`emitAckWithin` (`lib/socket.js`) and `lib/api.js` pass `error` through `tr()`, and the daily challenge's `goal` is translated where it is drawn. Messages with numbers or names inside (limits, "ya eligió esa casilla") have a rule in `PATTERNS` (`i18n.js`). A new server message needs its entry in `en.js` (the message exactly as the server sends it).
- The choice is in "Ajustes" (ES / EN), kept in `localStorage` (`trivially_lang`); first visit: the browser's language. It sets `<html lang>` and the tab's title too.
- Not translated on purpose: the content of the questions, answers, songs, countries, events and boards (the question bank is in Spanish; it would need a bank of its own), and names of people. Dates are written inside `tr()` (`pages/Legal.jsx`).
- A new text: write it in Spanish inside `tr("...")` and add its English to `en.js`. To find texts nobody wrapped yet, open the site in English and look for Spanish.
