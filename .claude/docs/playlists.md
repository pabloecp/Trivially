# Playlists (id `playlist`, `PLAYLIST_GAME`)

Several games, each with its own settings, played as one match. Not a game: no tile in the menu, opened from the dashed "Playlist" button (`PlaylistEntry` in `pages/Home.jsx`). `room.game === "playlist"` is its panel. Logic in `game/playlist.js`.

- **Making it:** `room.playlist` = `{ name, order: "orden"|"aleatorio", items: [{ id, game, config }] }`, ≤ 10 items (`PLAYLIST_LIMITS`). Socket `room:playlist` (`updatePlaylist`, host and co-hosts, lobby only) sends all of it; `cleanPlaylist`/`cleanItemConfig` keep it valid with each game's `merge*Config`. The lobby gets `playlistStatus` (per item `problem` and `counts`, cached by `cachedCount`).
- **Playing it:** `startPlaylist` checks every item (`itemProblem(..., { exact: true })`), creates `room.run` (`savedConfig` = the room's own settings), and `startMixed` draws all rounds (`drawItemTracks`; repeated games avoid each other's questions). "aleatorio" mixes them (`mixRounds`). Each track has `playlistItem`; `enterMixedRound` switches the room's game each round while scores add up. No tiebreak. The end: `finish` → `recordGame`, `endRun`, results at `/playlist/:code` (`Results.jsx`, `rankedStandings`).
- **Ending it:** `stopPlaylist` restores the room's settings; called by `restart`, `setGame` (during a run, back to the panel) and `replay`.
- **Sharing:** socket `playlist:share` stores it and returns a code `XXXXX-XXXXX` (`db/sharedPlaylists.js`, Supabase `shared_playlists`, else `backend/private/shared-playlists.json`); `playlist:byCode` loads it. The same playlist (sha256) always gets the same code; ≤ 10 codes/minute (`assertCanShare`); ≤ 20 KB; codes unused for a year are deleted (`forgetOldShareCodes`).
- **Library:** `localStorage` `trivially_playlists` (≤ 30); `saveToLibrary` never overwrites, duplicate names get "(2)".
- **Frontend** `modes/playlist/` (`LobbyPanel.jsx`, `ItemSettings.jsx`, `Standings.jsx`, `Results.jsx`, `playlistInfo.js`), styles `styles/playlist.css`. The settings panel switches "Juego" | "Guardar y compartir"; the list scrolls inside the card (`fitRows`, `MAX_ROWS` 5, `PHONE_ROWS` 4) with the add tray (`.tv-pl-tray`) under it.
