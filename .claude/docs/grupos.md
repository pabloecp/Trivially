# Groups (`game/groups.js`, tests `realtime/groups.test.js`)

A **group** is who goes together; a **room** is a match (its lobby, its rounds, its scoreboard). Nobody has a group on arrival: without one you play alone (a public match, or a private one only for you). "Sala" is no longer a word for players: it's "grupo" and "partida".

## Server
- `GroupManager` keeps groups in memory like the rooms (`groups` by code, `socketToGroup`). Codes come from `createRoomCode` and never repeat a room's or another group's.
- A group: `{ code, leaderId, members (Map: name, avatar, isGuest, connected, socketId), joinMode, joinRequests, blocked, plan: { game, audience }, roomCode }`. `publicGroup` is its only serializer (`group:state`, sent to each member's socket): members with `here` (with the group right now), `plan` ("Vas a jugar" on Inicio), `joinMode`, `joinRequests`, `place` (`{ code, public, game, own }`, null on Inicio). `place()` is the room at `roomCode` while a member is still in it.
- **The leader moves everyone** (sockets.js): `room:create` makes the group's private match (`room.groupCode`, host = leader) and `moveGroupTo` brings the others in; `match:find` gives everyone the group can take a seat in one public room (`findMatch(user, input, party)`, at most `PUBLIC_GROUP_MAX`, checked before anyone moves); `group:home` takes them back to Inicio from its private match, a search, or a finished public match (optional `plan`). `movable` skips the central device and members in the middle of a public match (they catch up on the next move). Each moved client hears `room:moved` (`{ code, state }`, or `{ code: null }` for Inicio). Only the leader can search, create or move (`assertLeader`).
- **Members on their own:** `room:leave` (a match's "X") goes to Inicio alone and stays in the group. `group:join` with the code (also "Ir con el grupo", and every reload) puts them where the group is (`follow`: into its private match, as a spectator if a round is on, or back to their own seat in its public one). `group:leave` also leaves its private match, except the last one (the group is gone and the match is theirs alone). Joining another group leaves the old one.
- **Leader = host of its private match:** `syncHost` after `group:leader` or a dropped leader's place running out; `room:giveHost` there makes the new host the leader; `room:kick`/`room:block` there also take them out of the group (`group:left`, reason "sacado"/"bloqueado"); `group:kick` does both.
- A dropped player keeps their place `GROUP_GRACE_MS` (20 s), the leader their role too; then `passLeader`. The same account still in the group from another live device (it has to answer `room:ping`): `offerRoom` (the group's private match) and the client joins it, which opens CentralOffer.
- Friends (`amigos-y-enlaces.md`): `friend:join` follows the group's `joinMode`, `friend:invite` sends the group's code, `group:answerJoin`, `group:joinMode`. FriendsHub shows a friend's `room.group`, `inRoom`, `inMatch`.

## Client
- `lib/store.jsx`: `group` (its code in `sessionStorage` `trivially_group`, per tab like the room), `createGroup`, `checkGroup`, `joinGroup`, `leaveGroup`, `groupHome`, `setGroupPlan`, `giveLeader`, `kickFromGroup`. `rejoin` does the group first (it can place the tab back in a room).
- The bar (`GroupBar.jsx`): without a group, "Crear grupo" (makes it at once, no window: a toast says to invite with "+") and, beside it on the left, "Unirse" (a box for a friend's code or invite link, "Código del grupo" as its placeholder, `codeFrom`, and the white "Unirse"; `checkGroup` first, so a wrong code is said under that side of the bar, `groupError`, before asking a name). With one, on the left and in this order: the red "Salir del grupo" ("Salir" on phones; it only asks: `HomeFrame` shows `ConfirmDialog` "¿Seguro que quieres salir del grupo?" with "Quedarme" and "Salir del grupo", and leaves only on the second), "Tu grupo", the faces (dimmed when not `here`) and "+"; the code isn't on the bar. "Tu grupo" (`GroupSheet.jsx`, from "+" or the faces) is the only place the code shows: the code box, then in its private match the match's column (`PartyPanel group`), elsewhere `GroupMembers` (the leader can make someone leader or take them out); the leader's `FriendsRoomControls` and `InviteFriends`.
- Invite link `/grupo/CODE` (`useInvite`; `Home.jsx` joins, asking for a name first, then goes to `/`). While the group's private match waits the address stays `/` (`roomPath`); `/sala/CODE` is only a public match's or a Clásico's while it plays (an older link still joins). `RoomNavigator` leaves a match's screens when the room is gone from under it.
- HomeFrame: non-leaders see "Esperando a Ana…" and a read-only "¿Qué quieren jugar?"; away from the group's private match, "Ir con el grupo"; while searching only the leader has CANCELAR ("Buscando con Ana…"). TvTopbar has no "Volver" while the group's match waits (it's Inicio); a match's "X": the leader where the group is = `group:home` ("Todo el grupo volverá al inicio contigo"), anyone else goes alone ("Seguirás en tu grupo"). Public results: the leader's "Volver" and "Buscar otra partida" are for everyone; the rest get "Volver" and "Esperando a Ana".
