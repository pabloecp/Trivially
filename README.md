## Juegos

- **Trivia**: preguntas de todos los temas, eligiendo entre cuatro opciones o escribiendo la respuesta.
- **Adivina la canción**: escucha un fragmento y adivina el título, o completa la letra.
- **Encuentra el país**: pon un pin en el mapa a partir del nombre, la silueta o la bandera del país.
- **Rango**: acércate lo más posible a una cifra.
- **Campo de minas**: elige las respuestas correctas de un tablero sin pisar las minas.
- **Lluvia**: las preguntas caen por la pantalla y cada una es de quien la responda primero.
- **Rey de la colina**: el rey elige la pregunta y quien la responda primero se queda con la corona.
- **Farsante**: todos inventan una respuesta y después votan cuál es la verdadera.

## Cómo se juega

- **Solo o en grupo**: con "Invitar" se forma un grupo y tus amigos entran con un enlace.
- **Partidas públicas**: juega con gente de todas partes.
- **Partidas privadas**: solo para tu grupo, con los juegos y ajustes que elijan.
- **Pantalla central**: una tele o una laptop muestra la partida y cada uno responde desde su teléfono.
- **Cuentas**: entra como invitado al instante o crea una cuenta para guardar tu perfil, tus estadísticas y tus amigos.

## Para desarrollar

Hace falta Node.js 18 o superior.

```bash
npm run install:all
npm run dev
```

La página queda en http://localhost:5173. Las variables de entorno están en [`.claude/docs/variables.md`](.claude/docs/variables.md) y la forma de trabajar con ramas y pull requests en [CONTRIBUTING.md](CONTRIBUTING.md).
